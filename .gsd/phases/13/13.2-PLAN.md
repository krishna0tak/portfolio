# Plan 13.2: Compact the 8-Phase Design Process Section

<objective>
The "DESIGN METHODOLOGY & WORKFLOW // 8-Phase Design Process" section renders 8 large cards in a 4-column grid. Each card has heavy padding (p-6), a step number header row, a title, description, bottom border, and a "PHASE X / 08" label. This makes the section take enormous vertical space — a massive block that doesn't need to be this heavy.

Goal: Replace the 8-card grid with a compact, minimal layout. Options in order of preference:
1. A tight 2-column numbered list (step number + title + short desc on one line each)
2. An 8-row compact table-like list with thin dividers
3. A 4×2 minimal compact grid with reduced padding (p-3 max) and no bottom footer row

The section should feel like a process checklist, not 8 feature announcement cards.

Purpose: Reduce visual weight, make the section scannable and minimal, consistent with the luxury minimal aesthetic of the rest of the site.
Output: Updated HeroSection.jsx with compact 8-phase steps layout.
</objective>
